# رصيدي — تطبيق إدارة الأموال الشخصية
نسخة أولية مستقلة عن مشروع «ميزانيتي»، بواجهة عربية داكنة وعملة الدينار العراقي.

## التشغيل
افتح `index.html` في متصفح حديث. على iPhone يمكن فتحه في Safari ثم اختيار «مشاركة» > «إضافة إلى الشاشة الرئيسية» إذا كان مستضافًا عبر HTTPS.

## المميزات في النسخة الأولية
- حسابات متعددة وأرصدة افتتاحية.
- دخل ومصروفات وتحويلات منفصلة.
- سجل عمليات محفوظ محليًا.
- أهداف ادخار وإضافة مساهمات.
- ديون وتسديدات تُسجل ضمن الدخل أو المصروف حسب نوع الدين.
- حدود إنفاق وتنبيه داخل الواجهة عند بلوغ 80% أو أكثر.
- اختيار يوم بداية الدورة المالية مع الاحتفاظ بالعمليات السابقة.
- تقارير دخل ومصروف حسب الفئة.
- تصدير واستعادة نسخة JSON.

## قيود مهمة
- البيانات محفوظة في تخزين المتصفح على الجهاز وليست متزامنة بين الأجهزة.
- إشعارات النظام خارج التطبيق غير مفعلة في هذه النسخة.
- هذه نسخة أولية؛ اختبر العمليات والنسخ الاحتياطي قبل الاعتماد عليها في السجلات المالية الفعلية.
